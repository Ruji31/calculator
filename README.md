# Scientific Calculator / Научный калькулятор

Веб-калькулятор с поддержкой базовых и инженерных вычислений, скобок, математических констант и функций.

## 🚀 Особенности

- **Вычисления:** Алгоритм Shunting Yard для корректной обработки приоритетов операторов и скобок.
- **Инженерные функции:** Тригонометрия (`sin`, `cos`, `tan`), квадратный корень (`sqrt`), степень (`^`), логарифмы (`log`, `ln`), факториал (`fact`) и модуль (`abs`).
- **Константы:** Быстрый ввод чисел $\pi$ и $e$.
- **Удобство ввода:** Поддержка ввода как с экрана (клики мышью), так и с физической клавиатуры.
- **Адаптивный интерфейс:** Автоматический подгон размера шрифта под длину результата и обработка ошибок (деление на ноль, некорректный ввод).

## 🛠 Технологии

- **HTML5** — структура
- **CSS3** — стили и адаптивный дизайн
- **JavaScript (ES6+)** — логика вычислений и обработка событий

## 📦 Запуск проекта

Просто открой файл `index.html` в любом современном браузере или запусти локальный сервер (например, через расширение **Live Server** в VS Code).
